# TurnFree

`TurnFree` - Android-приложение для запуска локального TURN/DTLS-клиента с автоматическим поднятием WireGuard-туннеля поверх него.

Проект использует:

- `com.wireguard.android:tunnel` для управления туннелем.
- нативный клиент `vk-turn-proxy` для установления DTLS-сессии.
- `Foreground Service` и постоянное уведомление для прозрачной работы в фоне.

## Что умеет приложение

- Импортировать конфиг из файла и из буфера обмена.
- Поддерживать `turnbridge://<base64>`, raw base64 и JSON-формат.
- Поднимать TURN-сессию, затем автоматически запускать WireGuard.
- Показывать статус подключения в интерфейсе и в уведомлении.
- Предлагать действия прямо из уведомления: открыть приложение или остановить соединение.
- Сохранять профиль и настройки между запусками.

## Поведение при первом запуске

При первом подключении приложение последовательно запрашивает системные разрешения, которые могут понадобиться для нормальной работы:

- уведомления;
- исключение из оптимизации батареи;
- доступ, необходимый для поднятия туннеля.

Если пользователь отказывается, приложение не блокируется и продолжает работу настолько, насколько это возможно.

## Как это устроено

1. Пользователь импортирует конфиг.
2. Приложение запускает foreground service.
3. TURN-клиент поднимает DTLS-сессию.
4. После успешного установления связи запускается WireGuard-туннель.
5. При ошибках приложение пытается переподключиться и обновляет статус в UI и уведомлении.

## Интерфейс

- Главная кнопка запускает или останавливает соединение.
- Расширенные параметры скрыты по умолчанию и раскрываются только вручную.
- Статус подключения и причина сбоя отображаются отдельно, чтобы было проще понять, что именно произошло.

## Требования

- Android `minSdk 24`.
- ARM64-устройство (`arm64-v8a`) для встроенного нативного клиента.

### Debug
